# FuckSeats Plugin API v1 前端接入指南

本文档只描述前端需要接入的页面、接口和交互协议。后端已实现 Plugin Core、本地 Runtime、云端 Runtime、Manifest、命令、Contribution、动态 UI、权限、生命周期、持久化、DevTools、热重载、插件包安装/更新/签名校验与插件市场索引。

## 1. 接入边界

- 本地桌面端基地址：`http://127.0.0.1:23948`
- 本地端接口均使用 Django Session；所有写请求携带 `X-CSRFToken`。
- 云端接口基地址由部署环境决定；需要登录态的插件 Action/Route 继续使用现有云端 Session Token。
- 云端插件启用、禁用、重载和卸载必须额外携带 `X-Plugin-Admin-Token`，该值只应由服务端管理界面注入，禁止写入前端构建产物。
- `trusted` 插件会在主进程加载 Python，权限声明是能力说明和 Host API 边界，不是 Python 沙箱。
- `sandboxed` 扩展只允许 Manifest + 声明式 Contribution，插件包中出现 Python 文件会被后端拒绝。
- Raw Workspace JS 仅为旧插件逃生通道；新前端优先实现 Command、Contribution、Workspace Slot 和动态 UI 协议。

## 2. 页面拆分

不同职责必须使用独立页面，不要把管理、安装、市场、开发调试和插件业务 UI 堆在同一个界面。

1. **插件管理页**：已安装插件列表、真实启用状态、版本、权限、启用/禁用、卸载入口。
2. **插件市场页**：市场插件列表、签名状态、已安装版本、可用更新、安装/更新入口。
3. **插件详情页**：Manifest、权限说明、Commands、Actions、Contribution、生命周期与更新地址。
4. **Plugin DevTools 页**：加载耗时、执行统计、最后错误、Reload、Action 调试。只面向开发模式或高级设置。
5. **插件设置页**：只展示该插件 `settings` 命名空间，不与管理页混用。
6. **插件业务 UI 页**：渲染 `page/blocks` 动态 UI，不放插件管理按钮。
7. **Command Palette**：工作区内使用 `Ctrl/Cmd + K` 打开，是独立浮层交互，不改造成插件管理页。

界面风格：主题色 `#0a59f7`，Apple 风格；顶栏使用半透明白色和模糊效果；内容占满浏览器可用区域；按钮使用胶囊样式；不要使用紫色渐变；不要使用 Emoji。

## 3. 本地端插件发现

### 3.1 获取完整插件清单

```http
GET /plugins/
Accept: application/json
```

响应结构：

```json
{
  "status": "success",
  "plugin_api_version": 1,
  "app_version": "2.6.2",
  "plugins": [
    {
      "id": "student_search_plugin",
      "name": "学生搜索插件",
      "version": "3.0.0",
      "enabled": true,
      "installed": true,
      "trust_level": "trusted",
      "api_version": {"min": 1, "max": 1},
      "app_requires": ">=2.6,<3.0",
      "permissions": [
        {"id": "students.read", "label": "读取学生信息", "known": true}
      ],
      "actions": [
        {"name": "search_students", "methods": ["GET", "POST"]}
      ],
      "commands": [
        {"id": "student.search", "title": "搜索学生"}
      ],
      "contribution_slots": ["workspace.toolbar", "workspace.panel", "seat.overlay"],
      "ui_scripts": [],
      "workspace_scripts": [],
      "load_duration_ms": 2.4,
      "loaded_at": "2026-08-21T00:00:00+00:00",
      "last_error": "",
      "manifest": {},
      "contributions": {}
    }
  ],
  "load_errors": []
}
```

前端要求：

- `enabled=false` 时仍显示插件，但禁止执行 Action、Command、UI 和 Workspace Script。
- `last_error`、`load_errors` 必须显示真实错误，不要用“运行正常”覆盖异常。
- 权限列表使用后端返回的 `label`；`known=false` 时显示原始权限 ID。
- `trust_level=trusted` 显示“主进程插件”；`sandboxed` 显示“声明式扩展”。不要把 trusted 描述成沙箱插件。

### 3.2 Extension Manifest

```http
GET /extensions/{plugin_id}/manifest.json
```

返回适合前端 Runtime 的聚合 Manifest，包含：

- `plugin_api_version`
- `enabled`
- `trust_level`
- `permissions`
- `commands`
- `plugin_actions`
- `plugin_commands`
- `plugin_contributions`
- `plugin_ui_scripts`
- `plugin_workspace_scripts`
- `endpoints`

## 4. Command 系统

### 4.1 获取命令

```http
GET /plugins/api/commands/
GET /plugins/api/commands/?placement=command_palette
GET /plugins/api/commands/?placement=workspace.toolbar
```

单个命令结构：

```json
{
  "plugin_id": "student_search_plugin",
  "id": "student.search",
  "title": "搜索学生",
  "description": "按姓名或学号搜索当前班级学生",
  "shortcut": "Ctrl+Shift+F",
  "action": "search_students",
  "placements": ["command_palette", "workspace.toolbar"],
  "permissions": ["students.read"],
  "stats": {
    "count": 0,
    "errors": 0,
    "average_duration_ms": 0,
    "last_duration_ms": 0,
    "last_executed_at": "",
    "last_error": ""
  }
}
```

### 4.2 执行命令

```http
POST /plugins/{plugin_id}/commands/{command_id}/
Content-Type: application/json
X-CSRFToken: CSRF_TOKEN

{
  "classroom_id": 12,
  "query": "张",
  "limit": 20
}
```

响应：

```json
{
  "status": "success",
  "plugin": "student_search_plugin",
  "command": "student.search",
  "result": {
    "query": "张",
    "count": 1,
    "items": []
  }
}
```

Command Palette 接入规则：

- `Ctrl/Cmd + K` 打开，命令自己的 `shortcut` 直接触发同一命令。
- 工具栏、右键菜单、快捷键和 Command Palette 都引用同一 `command.id`，不要复制业务执行逻辑。
- 执行期间显示 loading；HTTP `409` 表示插件已禁用或操作被干预型 Hook 取消。
- 命令返回 `{"handled_by":"frontend"}` 时，由前端根据该命令对应 Contribution 完成导航或显示。

## 5. Contribution 与 Workspace Slots

### 5.1 获取 Contribution

```http
GET /plugins/api/contributions/
GET /plugins/api/contributions/?slot=workspace.toolbar
GET /plugins/api/contributions/?slot=workspace.panel
GET /plugins/api/contributions/?slot=seat.overlay
```

通用字段：

```json
{
  "id": "student-search",
  "plugin_id": "student_search_plugin",
  "slot": "workspace.toolbar",
  "label": "搜索学生",
  "command": "student.search",
  "icon": "search"
}
```

前端至少实现以下 Slot：

| Slot | 渲染位置 | 必要字段 |
|---|---|---|
| `workspace.toolbar` | 工作区工具栏 | `id`、`label`、`command` |
| `workspace.sidebar` | 工作区侧栏 | `id`、`title`、`ui` 或 `command` |
| `workspace.panel` | 浮动/侧边面板 | `id`、`title`、`placement`、`ui`/`command` |
| `workspace.command_palette` | 命令面板 | `command` |
| `classroom.context_menu` | 班级菜单 | `label`、`command` |
| `student.context_menu` | 学生菜单 | `label`、`command` |
| `seat.badge` | 座位徽标 | `source`、`variant` |
| `seat.overlay` | 座位覆盖层/高亮 | `source`、`student_id_path`、`variant` |
| `classroom.header` | 班级标题区域 | `label`/`ui` |
| `settings.plugin` | 插件设置入口 | `plugin_id`、`settings_schema` |

未知 Slot 不应报错中断页面；记录到 DevTools，并保留原始 JSON 便于后续兼容。

### 5.2 学生搜索示例

`student_search_plugin` 不再依赖 `.seat`、`.unseated-item` 等 DOM Selector：

1. `workspace.toolbar` 渲染“搜索学生”入口。
2. 点击后执行 `student.search`。
3. `workspace.panel` 打开 `search_dashboard` 动态 UI。
4. `seat.overlay` 从 `result.items[].id` 读取学生 ID。
5. 前端通过现有学生/座位状态映射定位并高亮座位。

## 6. 动态 UI 协议

### 6.1 获取 UI 数据

```http
GET /plugins/{plugin_id}/ui/{ui_name}/?classroom_id=12
POST /plugins/{plugin_id}/ui/{ui_name}/
Content-Type: application/json

{"classroom_id": 12, "query": "张", "limit": 20}
```

页面壳地址：

```http
GET /plugins/{plugin_id}/ui/{ui_name}/page/?classroom_id=12
```

协议根节点：

```json
{
  "type": "page",
  "title": "学生搜索",
  "subtitle": "支持按姓名或学号搜索",
  "theme": {"primary": "#0a59f7", "style": "apple-like"},
  "blocks": []
}
```

组件列表：

```http
GET /plugins/components/
```

后端当前提供：

- 展示：`metric`、`text`、`list`、`table`、`progress`、`divider`、`section`、`badge`

所有组件可带 `span`，范围为 `1-12`；默认使用 12 列 Grid。未知组件使用只读 JSON Fallback，不要让整页崩溃。

### 6.3 Tabs、Modal 与 Button

- `tabs.items[]`：`id`、`label`、`blocks`；使用 `active` 指定初始 Tab。
- `modal`：`id`、`title`、`blocks`、可选 `trigger_label`。
- `button`：`label`、`action`、`method`、`payload`、`variant`。
- `alert.variant`：`info`、`success`、`warning`、`danger`。
- `button/actions/form` 最终都调用统一 Action Runtime，不要分别实现三套请求逻辑。

## 7. Action 与统一 Runtime 消息

直接调用 Action：

```http
POST /plugins/{plugin_id}/{action}/
Content-Type: application/json

{"classroom_id": 12, "key": "value"}
```

统一 Runtime：

```http
POST /extensions/{plugin_id}/runtime/send-message/
Content-Type: application/json

{
  "classroom_id": 12,
  "message": {
    "type": "action",
    "name": "search_students",
    "method": "POST",
    "payload": {"query": "张"}
  }
}
```

`message.type` 支持：

- `action`
- `command`
- `ui`
- `workspace_script`
- `manifest`

新前端优先直接使用 Command/Contribution/UI 对应接口；`runtime/send-message` 用于扩展宿主兼容。

## 8. 权限交互

权限来自 `plugin.permissions[]`。安装可信插件前必须显示完整权限清单和以下固定提示：

> 此插件将在 FuckSeats 主进程运行。权限声明用于说明和限制 Host API，但不构成 Python 安全沙箱。

Raw Workspace JS 的兼容授权：

```http
GET /extensions/{plugin_id}/permissions/?classroom_id=12
POST /extensions/{plugin_id}/permissions/

{"classroom_id": 12, "granted": true}
```

仅当 `workspace_scripts[].requires_permission=true` 时显示该授权。声明式 Contribution 不需要直接 DOM 写入授权。

## 9. 插件持久化设置

前端只开放 `storage` 和 `settings`；`secrets` 由插件后端 API 管理，禁止返回明文；`cache` 不持久化。

```http
GET /plugins/{plugin_id}/storage/settings/
GET /plugins/{plugin_id}/storage/settings/?key=page_size

POST /plugins/{plugin_id}/storage/settings/
{"key": "page_size", "value": 30}

DELETE /plugins/{plugin_id}/storage/settings/
{"key": "page_size"}
```

返回的 `keys` 仅用于构建设置页；字段标签、类型和校验应来自 `settings.plugin` Contribution 的 `settings_schema`，不要根据 key 名猜测 UI。

## 10. 插件管理与 DevTools

### 10.1 DevTools 数据

```http
GET /plugins/{plugin_id}/devtools/
```

展示：

- `enabled`
- `load_duration_ms`
- `loaded_at`
- Plugin API 范围
- Manifest 和权限
- Hooks/Actions/Commands/Routes/Contribution
- 每个 Action/Command 的 `count`、`errors`、平均耗时、最后耗时、最后执行时间和最后错误
- `load_errors`

### 10.2 控制插件

```http
POST /plugins/{plugin_id}/devtools/control/
Content-Type: application/json

{"operation": "disable"}
```

`operation`：`enable`、`disable`、`reload`、`uninstall`。

- `reload` 用于开发热重载；成功后重新请求插件清单、Commands 和 Contribution。
- `uninstall` 只执行生命周期和运行时卸载；若要删除安装目录，使用插件包移除接口。
- 管理按钮只放在插件管理/DevTools 页面。

## 11. 插件包、更新、签名与市场

### 11.1 安装或更新 ZIP

```http
POST /plugins/api/packages/install/
Content-Type: multipart/form-data

package=@plugin.zip
operation=install
confirm_trusted=true
```

更新时使用 `operation=update`。限制：

- ZIP 最大 25MB，解压后最大 100MB，最多 512 个文件。
- 拒绝路径穿越和符号链接。
- 包内必须且只能有一个 `plugin.yaml`、`plugin.yml` 或 `plugin.json`。
- `trusted` 插件必须传 `confirm_trusted=true`。
- 开启 `PLUGIN_REQUIRE_TRUSTED_SIGNATURE=1` 后，trusted 插件必须通过 Ed25519 签名。
- 更新前的版本自动备份到应用私有 `.runtime/backups/plugins`，不要在项目根目录生成备份。

签名字段：

```yaml
integrity:
  files:
    plugin.py: SHA256_HEX

signature:
  algorithm: ed25519
  key_id: official-2026
  value: BASE64_SIGNATURE
```

签名数据是以下 JSON 的 UTF-8 紧凑编码，键按字典序排列：

```json
{"files":{"plugin.py":"SHA256_HEX"},"id":"plugin_id","version":"1.0.0"}
```

公钥由环境变量 `PLUGIN_TRUSTED_PUBLIC_KEYS` 提供，值为 `{"key_id":"BASE64_RAW_ED25519_PUBLIC_KEY"}`。前端只展示 `signature_status` 与 `signature_key_id`，不处理私钥或自行跳过后端验证。

### 11.2 移除安装目录

```http
POST /plugins/{plugin_id}/package/
Content-Type: application/json

{"confirm_remove": true, "clear_data": false}
```

插件目录会移动到私有备份目录，随后 Runtime 重载。删除前显示实际影响；`clear_data=true` 会清除该插件的 storage/settings/secrets。

### 11.3 插件市场

```http
GET /plugins/api/marketplace/
```

未配置 `PLUGIN_MARKETPLACE_URL`：

```json
{"status":"success","configured":false,"plugins":[],"updates":[]}
```

已配置时后端只接受 HTTPS JSON 索引，并返回 `plugins` 与 `updates`。市场页使用 `updates[].update_available`，不要只比较字符串。

推荐 `plugin.yaml`：

```yaml
id: student_search_plugin
name: 学生搜索插件
version: 3.0.0

api_version: 1

requires:
  app: ">=2.6,<3.0"
  plugins:
    another_plugin: ">=1.0,<2.0"

entry: plugin.py
author: 老三
website: www.577622.xyz
license: GPL-3.0
trust_level: trusted

permissions:
  - plugin.runtime
  - classroom.read
  - students.read
  - workspace.ui
  - workspace.toolbar
  - workspace.command_palette
  - seat.overlay
  - storage

contributes:
  workspace:
    - slot: workspace.toolbar
      id: student-search
      label: 搜索学生
      command: student.search
```

前端必须区分：

- FuckSeats App Version
- Plugin Version
- Plugin API Version

API 不兼容或依赖缺失的插件会出现在 `load_errors`，不要当作普通禁用状态处理。

## 14. 错误码和刷新策略

| HTTP 状态 | 含义 | 前端动作 |
|---|---|---|
| `400` | 请求、Manifest、插件包或组件字段错误 | 显示后端 `message` |
| `401` | 云端登录态或插件管理员凭据无效 | 进入对应登录/管理员校验流程 |
| `403` | Raw Workspace Script 未授权 | 打开该班级的授权确认 |
| `404` | 插件/Action/Command/UI 不存在 | 刷新插件清单 |
| `405` | 请求方法不在插件声明范围 | 修正调用方法，不自动重试 |
| `409` | 插件禁用或干预型 Hook 取消操作 | 显示原因并保持当前页面状态 |
| `500` | 插件执行异常 | 显示错误并在 DevTools 查看统计 |
| `502` | 插件市场索引读取失败 | 显示真实错误，允许手动刷新 |

执行以下操作后刷新对应数据：

- enable/disable/reload/uninstall：刷新清单、Commands、Contribution、当前插件 Manifest。
- 安装/更新/移除插件包：刷新全部插件数据，并卸载已经渲染的旧 Workspace Contribution。
- Form/Action/Command 写入班级数据：继续复用现有班级状态刷新机制。

## 15. 前端请求封装示例

```javascript
async function pluginRequest(url, options = {}) {
  const headers = new Headers(options.headers || {});
  const csrf = document.querySelector('[name="csrfmiddlewaretoken"]')?.value || '';
  if (csrf && !headers.has('X-CSRFToken')) headers.set('X-CSRFToken', csrf);
  if (options.body && !(options.body instanceof FormData) && !headers.has('Content-Type')) {
    headers.set('Content-Type', 'application/json');
  }

  const response = await fetch(url, {
    credentials: 'same-origin',
    ...options,
    headers,
  });
  const payload = await response.json().catch(() => ({
    status: 'error',
    message: `HTTP ${response.status}`,
  }));
  if (!response.ok) {
    const error = new Error(payload.message || `HTTP ${response.status}`);
    error.status = response.status;
    error.payload = payload;
    throw error;
  }
  return payload;
}
```

## 16. 验收清单

- 插件管理、市场、详情、DevTools、设置、业务 UI 已拆成独立页面。
- 插件清单能区分 enabled、load error、API 不兼容和依赖缺失。
- Command Palette、工具栏、快捷键执行同一 Command。
- Contribution Renderer 不依赖插件直接查询 `.seat` 等内部 DOM。
- 学生搜索能通过 `seat.overlay` 结果定位座位。
- 旧 Raw Workspace JS 仍需班级级授权，撤销后执行返回 `403`。
- 动态 UI 能渲染全部 19 种组件，未知组件有 JSON Fallback。
- Form 字段校验、loading、错误和成功刷新完整。
- enable/disable/reload 后已挂载 Contribution 能正确卸载和重建。
- DevTools 显示真实执行次数、错误次数、耗时和最后错误。
